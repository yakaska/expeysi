# AGENTS.md

## Проект

Expeysi — Android-приложение совместного учёта доходов и расходов для минимум двух
пользователей. Монорепо: `android/` (приложение), `firebase/` (правила Firestore),
`docs/` (план и решения). Функциональность намеренно минимальная — не добавляем
фичи сверх списка в README без явного запроса.

## Стек

- Только Android, Jetpack Compose, дизайн Material 3
- Локальное хранилище: Room, DI: Hilt
- Синхронизация: Firebase Firestore + Firebase Authentication через Google
- Виджеты: Jetpack Glance
- Фоновая работа: WorkManager (при необходимости)
- Своего сервера нет и не планируется

## Строки UI (локализация)

Никаких хардкод-строк в пользовательском интерфейсе. Любой текст, который видит пользователь, живет в ресурсах.

- Строки: res/values/strings.xml того модуля, где они используются. Язык исходных строк - русский. Переводы не создавать.
- Ключи: snake_case с префиксом экрана/фичи (login_title, profile_error_network). Общие - common_ (common_ok, common_retry). Перед добавлением проверить, нет ли такой строки; дубликаты не плодить.
- Параметры: только позиционные (%1$s, %2$d), без конкатенации строк.
- Зависимость от числа: <plurals>, не if/else.
- Не переводимое (бренд, технические идентификаторы): translatable="false".
- Спецсимволы экранировать (', &, <, @, ?).

Использование:
- Compose: stringResource(R.string.x), pluralStringResource
- View/Fragment/Activity: getString(R.string.x)
- XML: @string/x
- ViewModel/Presenter: Context не передавать. Использовать UiText (StringResource + args) или @StringRes Int, резолвить в UI-слое.

Не считается UI-строкой: логи, ключи SharedPreferences/DataStore, extras, routes, теги, URL, regex, JSON-ключи, строки в тестах.

Перед завершением задачи: проверить diff на новые литералы в Text(), setText, Toast, Snackbar, AlertDialog, android:text/hint/contentDescription, android:label. Прогнать ./gradlew lint.

## Зафиксированные решения

- Синхронизация через Firebase Firestore. Бесплатный тариф Spark, realtime-слушатели,
  встроенный офлайн-кэш SDK. Онбординг: один пользователь создаёт «семью», второй
  присоединяется по коду.
- Room на телефоне остаётся источником правды для UI, Firestore хранит общий журнал
  изменений семьи.
- id записей — UUID. Суммы — Long в минимальных единицах валюты (копейки).
  Баланс не хранится, а считается: начальный остаток счёта + доходы − расходы.
- Удаление мягкое (флаг `deleted`). Конфликты — last-write-wins по `updatedAt`.
- Предзаписанные категории и счета (наличные, карта) получают одинаковые
  детерминированные UUID на всех устройствах, чтобы после синка не было дубликатов.
- Иконка категории хранится ключом-строкой (`iconKey`) из фиксированного набора
  Material Icons. Неизвестный ключ рисуется иконкой по умолчанию.
- Неделя считается с понедельника; день и месяц — по локальному часовому поясу телефона.

## Процесс

- Работаем в feature-ветках (`feature/<краткое-имя>`), мержим в `main`.
- Коммит, pull request и merge делаем только по явному указанию пользователя
  («закаммить», «сделай пр», «мерджи»). Правки сами не фиксируем: изменения
  остаются в рабочем дереве, пока пользователь не скажет закоммитить.
- Порядок этапов и условия готовности — в `docs/plan.md`. К следующему этапу
  переходим только после выполнения условия готовности предыдущего.
- Секреты (google-services.json, keystore) не коммитим; в репозитории — только
  шаблоны и инструкции.
## Команды

Выполняются из каталога `android/` (Windows, Git Bash):

- `./gradlew :app:assembleDebug` — собрать debug APK
- `./gradlew :app:testDebugUnitTest` — unit-тесты (JVM, без эмулятора)
- `./gradlew :app:installDebug` — установить на подключённое устройство

SDK находится через `android/local.properties` (`sdk.dir=...`), файл в `.gitignore`.
