# Expeysi — учёт расходов для двоих

Expeysi — Android-приложение для совместного учёта доходов и расходов. Оно рассчитано
на небольшую группу, минимум двух человек: например, двое записывают свои траты в
один общий журнал и видят чужие записи у себя на телефоне. Своего сервера нет —
данные синхронизируются через Firebase и хранятся локально на каждом устройстве.

> Приложение в ранней стадии разработки, функция за функцией. Готовый APK можно
> взять со страницы [Releases](https://github.com/yakaska/expeysi/releases).

## Что умеет

- Запись доходов и расходов: сумма, счёт, категория, дата, комментарий; запись можно править.
- Категории и счета: предзаписанные («Еда», «Транспорт», «Наличные», «Карта») плюс свои, с иконками и цветами.
- Балансы: группы счетов с общей валютой (пример — «Основной» в рублях). Можно вести несколько балансов в разных валютах.
- Совместный учёт: один создаёт «семью», остальные присоединяются по коду приглашения. Записи появляются на всех устройствах почти мгновенно; офлайн-изменения синхронизируются при появлении сети.
- Анализ: «Анализ финансов» — распределение по категориям за выбранный период; «Сравнение» — итог и операции по выбранным категориям; «История» — перечень операций по балансу или счёту.
- Экспорт и импорт данных в CSV, формат совместим с приложением «Бюджет» (импорт-экспорт туда и обратно сходится).

Виджеты на рабочий стол запланированы, но пока не реализованы.

## Как устроено

Главный экран показывает выбранный баланс: итоговые суммы за сегодня, 7 и 30 дней,
остаток по каждому счёту и последние операции. Баланс здесь — не «сколько денег»,
а группа счетов («Наличные», «Карта», свои) с общей валютой. Остаток счёта не
хранится, а считается: начальный остаток + доходы − расходы.

Данные живут в двух местах:

- Локальная база Room на телефоне — источник для интерфейса, работает без интернета.
- Firestore (облако Firebase) — общий журнал семьи. Каждое устройство пишет туда
  свои изменения и слушает чужие; очередь недоставленных записей и повтор при
  появлении сети обрабатывает сам Firestore SDK.

Вход — через Google-аккаунт и Firebase Authentication. Код приглашения — это
идентификатор документа семьи в Firestore; для каждого устройства создаются
предзаписанные категории и счета с одинаковыми идентификаторами, поэтому после
синхронизации не бывает дубликатов. Подробности — в [docs/data-model.md](docs/data-model.md).

## Установка

Требуется Android 8.0 или новее и Google-аккаунт для входа.

1. Откройте страницу [Releases](https://github.com/yakaska/expeysi/releases).
2. Скачайте `Expeysi-<версия>.apk` с последнего релиза.
3. Установите APK на телефон (Android может попросить разрешить установку из неизвестных источников).
4. Запустите приложение, войдите через Google и создайте семью или присоединитесь по коду.

Первый пользователь создаёт семью — приложение покажет код приглашения. Остальные
вводят этот код на экране входа в семью.

## Сборка из исходников

Для сборки нужны Android SDK (API 36) и JDK 17. Путь к SDK задаётся в
`android/local.properties` (строка `sdk.dir=...`; файл в `.gitignore`).

Работа с Firebase описана в [firebase/README.md](firebase/README.md): там нужно
создать проект, включить Google-вход и скачать `google-services.json` в
`android/app/` — без него сборка не пройдёт. Этот файл и release-keystore в
репозиторий не коммитятся.

Команды выполняются из каталога `android/` (Windows, Git Bash):

```bash
./gradlew :app:assembleDebug      # собрать debug APK
./gradlew :app:testDebugUnitTest  # unit-тесты, без эмулятора
./gradlew ktlintCheck lint        # стиль кода и Android lint
./gradlew :app:installDebug       # установить на подключённое устройство
```

Публикация релизов — отдельный процесс, описан в [docs/releases.md](docs/releases.md).
