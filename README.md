# Expeysi — учёт расходов для двоих

Android-приложение для совместного учёта доходов и расходов (минимум 2 пользователя).
Jetpack Compose, Material 3, синхронизация через Firebase Firestore. Без своего сервера.

## Функции

1. Запись дохода
2. Запись расхода
3. Категоризация доходов и расходов по предзаписанным категориям + свои категории с иконками из фиксированного набора
4. Два виджета: расход и доход за день / неделю / месяц
5. Счета: наличные, банковская карта + свои счета

## Структура монорепо

- `android/` — приложение (Jetpack Compose, Material 3)
- `docs/` — план, решения, контракты данных
- `firebase/` — правила Firestore, конфигурация

Детали процесса и зафиксированные решения — в `AGENTS.md` и `docs/plan.md`.
